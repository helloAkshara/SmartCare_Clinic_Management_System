# 🏥 SmartCare
### Clinic Management & Rule-Based Triage System

> A Java-based clinic management system developed for the **VITyarthi Programming in Java Project**.

---

## 📌 Overview

**SmartCare** is a console-based Java application designed to manage basic clinic operations such as patients, doctors, appointments, medical records, and patient history.

It also includes an **educational rule-based triage system** that classifies cases into **LOW, MEDIUM, or HIGH priority** based on selected symptoms and severity.

> ⚠️ **Disclaimer:** This is an educational simulation and does not provide medical diagnosis.

---

## ✨ Features

| Module | Functionality |
|---|---|
| 👤 Patients | Register, view & search patients |
| 👨‍⚕️ Doctors | Register & view doctors |
| 🩺 Triage | Symptom & severity-based priority |
| 📅 Appointments | Book & manage appointments |
| 📋 Medical Records | Add & view patient records |
| 📊 Reports | Generate daily clinic reports |

## 🚀 Installation & Running

### Requirements
- Java JDK 8 or above
- IntelliJ IDEA
- Git

### Steps
1. Install Java JDK 8 or above.
2. Clone the GitHub repository.
3. Open the project in IntelliJ IDEA.
4. Open `src/Main.java`.
5. Run the `Main` class.
